# 🌱📔 Legacy Planner

**Browser-based reflection planner covering family, spiritual life, health, time, finances, business, vision, and goals with local fields and export controls.**

🏷️ Maintained in [qamotech/cflife](https://github.com/qamotech/cflife) · 🌐 Public repository

## ✨ What is here

- 👪 Spiritual, marriage, kids, and family-culture reflection sections.
- 🌿 Health, time, finance, and legal-planning prompts.
- 🧭 Business, vision, goal mapping, and closing reflections.
- 💾 Browser-local fields and JSON-style data export.

## 🧭 Try the project

Serve on a dedicated local origin, select a section, enter non-sensitive sample reflections, and export a backup before trying reset controls.

## 🚀 Local setup

```sh
git clone https://github.com/qamotech/cflife.git
cd cflife
```

Use a current browser. Serve the repository root to preserve relative assets and a stable browser origin:

```sh
python -m http.server 8000
```

Open `http://localhost:8000/index.html`. Keep related assets beside the entry file. No npm setup is declared in the inspected repository.

## ⚙️ Configuration & data

The current export serializes the origin localStorage and reset calls localStorage.clear(), so use a dedicated origin to avoid mixing other apps’ data. Fields are not encrypted. Prompts are not professional financial, legal, or medical advice.

Keep credentials, private exports, customer records, and personal information out of commits and screenshots. A local browser demo is not evidence of account security, reliable persistence, or connected external services. Preserve exports before changing storage keys or resetting an application.
